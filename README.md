# SifoSchool

Independent school management platform by Sifonet Technologies.

## Product boundary
SifoSchool is a standalone application and repository. It is not a SifoBooks module and will use its own deployment and, when configured, its own Supabase project.

## Initial scope
- School dashboard and academic-year overview
- Student records, admissions and guardians
- Classes, streams and subjects
- Attendance and timetables
- Assessments, examinations and results
- School fees, invoices, receipts and balances
- Staff records and permissions
- Reports and audit history

## Development
This repository starts with a React + TypeScript + Vite frontend shell. Backend credentials and Supabase integration are intentionally not configured yet.

```bash
npm install
npm run dev
```
